全标段质量检测统计台账系统 - 使用说明
========================================

一、系统概述
本系统为单机版浏览器网页，无需服务器、无需账号、完全离线运行。用于汇总各标段质量检测数据，生成结构化 Excel 电子表格形式的《全标段质量检测统计台账》。

二、启动方式
1. 双击 index.html 用 Chrome 或 Edge 浏览器打开（建议 Chrome ≥ 90 或 Edge ≥ 90）。
2. 首次打开会自动初始化数据库并加载默认配置。

三、使用流程
1. 配置基础信息
   - 进入「系统设置」Tab，填写工程名称、工程编号、录入员姓名、所属单位。
   - 在「标段单位工程」Tab 查看/维护标段、单位工程、分部工程清单。系统已内置温潮减河工程项目划分（8 标段 / 35 单位工程 / 186 分部工程），来源《北京市水务建设管理事务中心关于温潮减河工程项目划分的函》（京水建管〔2024〕173号）。
   - 在「系统设置」Tab 维护施工/监理签字人清单、检测单位清单。

2. 下载台账模板
   - 进入「上传」Tab，点击「下载台账模板」，将模板分发给各标段负责人填写。
   - 模板通用字段含「分部工程*」列，须填写项目划分清单中的分部工程名称（可在「标段单位工程」Tab 查询）。
   - 各标段负责人按模板填写本标段检测数据后，交回给录入员。

3. 上传台账文件（Excel / Word）
   - 录入员在「上传」Tab 拖拽或点击选择台账文件。
   - 支持 .xlsx / .xls / .docx：Excel 按 sheet 名识别类别；Word（.docx）按文档中的表题/标题识别类别，读取其中的表格数据；表格首行须为与模板一致的表头。
   - 旧版 .doc（二进制）无法直接解析，请在 Word 中「另存为 .docx」后重新上传。
   - 系统自动解析、校验、去重，归入台账。
   - 格式不符的行会被拒绝，并自动生成「错误清单」Excel 供核对修正后重传。
   - 【标准模式】使用系统「下载台账模板」填写的文件按严格规则校验（报告编号/试件编号/标段/单位工程/分部工程/规格/检测日期/类别必填项缺一不可）。
   - 【见证台账宽松导入】各标段提供的「100%见证」类 Word/Excel 台账通常缺标段、单位工程、分部工程、规格等信息。系统会自动识别此类台账（表头含「试验编号/试验项目/代表部位/试验结果」等），并自动宽松导入，无需手动操作；标准模板导入失败时也会自动降级为宽松模式。手动勾选「见证台账宽松导入」可强制宽松：
     · 允许上述字段为空先行入库；报告编号、试件编号取「试验编号」列，部位取「代表部位」列，判定取「试验结果」列（合格/不合格），组数取「组数」列；
     · 表题无法确定类别时，按每行的「试验项目/试件（材料）名称/检测依据」自动识别检测类别（一张表可含多种试验项目）；
     · 仅含序号的预留空行自动跳过；
     · 有「试验编号」的行视为已有依据，直接入库，无需再补标段/单位工程/分部工程/规格；仅无试验编号的行在「台账」中带「待补录」标记，可用筛选栏「仅看待补录」集中补录编号。

4. 查看台账
   - 「台账」Tab 可按标段/类别/判定筛选，双击单元格可编辑，点击「删除」可软删除（可在底部恢复）。

5. 查看看板
   - 「看板」Tab 展示标段×类别合格率矩阵、不合格清单、总览统计卡片。

6. 导出台账
   - 「系统设置」Tab：
     - 「导出全量台账 Excel」：按类别分 sheet 导出全部记录。
     - 「生成月度台账快照」：生成含「汇总看板/本月新增/全量台账/不合格清单」4 sheet 的 Excel，并同步生成 JSON 备份。
     - 「导出 JSON 全量备份」：导出 IndexedDB 全部数据为 JSON，用于数据迁移或备份。

四、数据存储
- 所有数据存储在录入员本机浏览器的 IndexedDB 中，关闭浏览器不会丢失。
- 清理浏览器数据会丢失台账数据，建议定期用「导出 JSON 全量备份」做冷备份。
- 系统不联网、不上传任何数据到服务器。

五、判定标准
默认标准依据《水利工程建设质量检测管理规范》DB11/T 3032-2022（北京市地方标准，2022-11-01 实施）附录F《施工单位质量检测项目、内容和频次》：
- 混凝土抗压强度：试验方法 SL/T 352 / GB/T 50081；频次按 SL 677（大体积混凝土每 500m³ 成型一组，结构混凝土每 100m³ 成型一组，不足亦成型一组）；强度评定按 SL 176 及 GB/T 50107（95% 保证率，n≥3 统计法，n<3 非统计法）。依据 DB11/T 3032-2022 表F.58。
- 钢筋原材拉伸：GB/T 1499.1（热轧光圆）/ GB/T 1499.2（热轧带肋）/ GB/T 28900（试验方法）；频次每批同一牌号、同一炉罐号、同一尺寸，每批≤60t；常规检测项含下屈服强度、抗拉强度、断后伸长率、最大力总延伸率、弯曲性能、重量偏差。依据 DB11/T 3032-2022 表F.17、表F.18。
- 钢筋焊接接头：JGJ/T 27（试验方法）/ JGJ 18（验收）；频次同一台班同一焊工 300 个同牌号同直径接头为一批；闪光对焊每批切 6 个（3拉3弯），电弧焊/电渣压力焊切 3 个拉伸，气压焊竖向 3 拉、水平 3 弯。依据 DB11/T 3032-2022 表F.60～表F.63。
- 已扩充检测类别（依据 DB11/T 3032-2022 附录F 及相关分项规范）：砂浆抗压强度（SL/T 352）、混凝土抗折(弯拉)强度（SL/T 352 / JTG/T F30）、混凝土抗渗性能、混凝土抗冻性能（SL/T 352 / GB/T 50082）、土方压实度（SL 237 / JTG 3430）、钢筋机械连接接头（JGJ 107）、预应力钢绞线（GB/T 5224）、桩身完整性（JGJ 106）、水泥原材（GB 175）。合计 12 个检测类别。
- 判定标准可在 assets/config/default-standards.json 中修改；也可在「类别管理」Tab 点击"重新加载默认类别/标准配置"同步。

六、扩展新检测类别 / 调整项目划分
0. 调整标段、单位工程、分部工程清单：编辑 assets/config/default-project.json，然后在「标段单位工程」Tab 点击"重新加载项目划分清单"（已有检测记录不受影响）。
1. 编辑 assets/config/default-categories.json，按现有格式新增类别（key/name/fields/spec_enum_key/standard_ref，可参照 DB11/T 3032-2022 附录F 相应表确定检测项与频次）。
2. 在 assets/config/default-specs.json 中添加对应的规格枚举。
3. 在 assets/config/default-standards.json 中添加判定标准。
4. 在「类别管理」Tab 点击"重新加载默认类别/标准配置"（或清空 categories/standards 表后刷新）。

七、注意事项
- 标段、单位工程、分部工程与规格均须与系统清单一致，否则上传时会被拒绝；其中「分部工程」须与该单位工程的项目划分清单名称完全匹配。
- 报告编号+试件编号 联合唯一，重复导入会被拒绝。
- 同一 Excel 文件只能导入一次（按文件内容哈希去重）。
- 签字日期从 Excel 读取，不默认当天。
- 双击 index.html 以 file:// 打开时浏览器会拦截配置文件读取，系统自动改用内嵌默认配置，功能不受影响；通过本地 HTTP 服务打开时优先读取 assets/config 下的 JSON。
